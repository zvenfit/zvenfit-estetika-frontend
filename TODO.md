# ZvenFit Estetika — список задач

Состояние проверено **2026-08-09**: `estetika.zvenfit.ru` и основные пути отвечают HTTP 404, `www.estetika.zvenfit.ru` не резолвится, последний GitHub Actions run для `5335fff` завершился ошибкой авторизации Yandex Cloud. Руководство для агентов: [`AGENTS.md`](AGENTS.md).

## Ближайший порядок работ

1. **Вернуть независимую проверку кода в CI** — отделить lint/test/build от деплоя функции и добавить безопасную проверку обязательной конфигурации.
2. **Восстановить доступ CI к Yandex Cloud** — проверить или перевыпустить ключ сервисного аккаунта и остальные secrets/variables.
3. **Закрыть минимальную надёжность форм до приёма реальных заявок** — доверенный IP, таймауты Telegram и клиента, понятные ошибки, безопасное поведение без JavaScript.
4. **Закрыть юридические блокеры** — подтвердить владельца данных, реквизиты, тексты и фиксацию отдельных согласий.
5. **Развернуть функцию и сайт** — получить URL функции, собрать сайт с ним, загрузить `dist/` в бакет и очистить закешированные CDN-ответы 404.
6. **Провести release smoke-test** — страницы, пользовательская 404, юридические документы, одна маркированная заявка, одна подписка и Метрика.
7. **Включить базовые security headers на CDN** — сначала обратимые заголовки; HSTS только после проверки стабильного HTTPS.
8. **До рекламного трафика** — API Gateway + Smart Web Security, CSP, логирование и уведомления расходов. Производительность, SEO и контент вести после восстановления production, если они не блокируют юридическую проверку.

## Безопасность и надёжность

- [x] **Надёжное хранение заявок** — заявка или подписка сохраняется в YDB до отправки Telegram; UUID обеспечивает идемпотентность, минутный timer повторяет доставку с lease и backoff
- [x] **Доверенный IP в функции** — `event.requestContext.identity.sourceIp` имеет приоритет над клиентским `X-Forwarded-For`; добавлен тест на поддельный XFF
- [x] **Таймаут Telegram API** — `fetch` ограничен пятью секундами; ошибка фиксируется без персональных данных, повтор выполняется из сохранённой записи без повторного создания заявки
- [ ] **Таймаут клиентских запросов** — добавить `AbortSignal` в форму заявки и форму рассылки, вернуть понятное сообщение при недоступности API
- [ ] **Надёжный rate limit перед рекламным трафиком** — текущий `Map` работает только внутри одного тёплого экземпляра функции и остаётся best-effort защитой
  - [ ] Поставить перед функцией API Gateway + Smart Web Security Advanced Rate Limiter с лимитами на POST по IP и общим аварийным лимитом
  - [ ] Закрыть прямой публичный вызов функции, чтобы Gateway/SWS нельзя было обойти
  - [ ] Настроить бюджет и уведомления расходов
- [ ] **HTTP-заголовки безопасности на Cloud CDN** — добавить как статические заголовки ответов клиентам на CDN, а не через HTML `<meta>` ([документация Yandex Cloud CDN](https://yandex.cloud/ru/docs/cdn/operations/resources/configure-headers))
  - [ ] `Strict-Transport-Security: max-age=31536000` — включать после восстановления production и проверки HTTPS; пока без `includeSubDomains` и `preload`
  - [ ] `X-Content-Type-Options: nosniff`
  - [ ] `X-Frame-Options: DENY`
  - [ ] `Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=(), usb=()`
  - [ ] `Referrer-Policy: strict-origin-when-cross-origin`
  - [ ] Проверить заголовки для `/`, `/form/`, `/404.html` и юридических страниц командой `curl -I` после распространения настроек CDN
- [ ] **Content Security Policy** — вынести исполняемый inline-код, запустить CSP сначала в `Report-Only`, учесть домены Яндекс Метрики, затем включить enforcement с `frame-ancestors 'none'`
- [x] **Логирование ошибок заявок** — ошибки YDB/Telegram и исчерпание попыток пишутся структурированно без имени, телефона, Telegram и IP

Для первой версии не требуется.

- [ ] **Top.Mail.Ru / GTM** — основной сайт использует дополнительные теги; в estetika сейчас только Яндекс Метрика
- [ ] **Пиксель VK** — вне объёма работ, пока не появится запрос маркетинга
- [ ] **Расписание / Fitbase** — неприменимо для estetika
- [ ] **Кнопки загрузки приложения** — неприменимо
- [ ] **Загрузка фотографий организации из Яндекс Карт при сборке** — неприменимо, блока карты нет
- [ ] **Система маркеров сниппетов для 26 страниц** — избыточна для трёх страниц; текущая сборка вставляет данные перед `</head>`
- [ ] **Prettier и тяжёлый набор ESLint** — в основном сайте есть правила TS/React, здесь используется минимальный `eslint:recommended`

Перенос jQuery в собственный CDN больше не относится к необязательному паритету: `webflow.js` использует `window.jQuery`, поэтому эта работа включена в блокеры запуска.
