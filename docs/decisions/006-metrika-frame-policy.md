# ADR-006. Встраивание страниц сайта в Яндекс Метрику

23 ноября 2026 года. Дополняет [ADR-004](004-cdn-security-headers-from-repository.md).
Решение принято для конфигурации. [Проверка на production](../../TODO.md#безопасность-и-надёжность) открыта.

На картах кликов, ссылок и скроллинга браузер показал во фрейме текст
«estetika.zvenfit.ru refused to connect.». Визиты на главную за выбранный период
подтверждены. Отдельный GET к адресу фрейма `/?_ym_debug=1` вернул HTTP 200
и `X-Frame-Options: DENY` без CSP.

На всём CDN-ресурсе `estetika.zvenfit.ru` задаём HTTP-заголовок
`Content-Security-Policy: frame-ancestors https://metrika.yandex.ru`. Новые страницы
наследуют правило. Оно разрешает указанному origin встраивать в том числе подписку
на главной и страницу записи. Разрешение действует для всего origin, независимо от
номера счётчика и пути страницы. Клиенты с поддержкой только `X-Frame-Options`
сохраняют защиту `DENY`. Встраивание и сбор событий проверяются отдельно.

Правило для отдельных путей потребовало бы поддерживать список страниц сайта.
Выбранный origin соответствует входу, через который проверяли карты. Для расширения
перечня нужен фактический адрес предка из браузера и подтверждение его назначения.
Ограничения загрузки скриптов, стилей и других ресурсов относятся к полной CSP.
