# ADR-005. Ежедневная проверка публичного сайта и сертификата

23 ноября 2026 года. Дополняет [ADR-004](004-cdn-security-headers-from-repository.md).

Между деплоями могут пройти недели. За это время оператор может изменить заголовки в консоли
CDN, а сертификат, который получают посетители, может приблизиться к истечению срока.

Обе проверки выполняет отдельный GitHub Actions workflow. Обычный клиент HTTPS видит результат
на публичном домене. Ему достаточно доступа к сети и чтения репозитория. Проверка использует
существующий контракт заголовков и проверяет сертификат непосредственно при TLS-соединении с CDN.

Текущие правила Monium в `scripts/monitoring.config.json` охватывают Cloud Function, YDB
и доставку заявок. У них нет источника для HTTP-заголовков, которые получает посетитель.
Метрика срока сертификата в Certificate Manager характеризовала бы объект в облаке.
Проверка на CDN учитывает и то, какой сертификат фактически выбран для домена.

Операционный сигнал — неуспешный запуск Site health. Он зависит от расписания GitHub
и настроек уведомлений ответственного. [Порядок проверки и восстановления расписания](../setup.md#ежедневная-проверка-сайта).
