# UTM в заявках ZvenFit Эстетика — инструкция для маркетинга

Кратко: метки из рекламных ссылок сохраняются в браузере и попадают в **Telegram** вместе с заявкой (форма записи или подписка на рассылку). Срок хранения — **7 дней с последнего успешного обновления записи** на сайте.

---

## Что настраивать в рекламе

| Параметр       | Пример              | Зачем                          |
|----------------|---------------------|--------------------------------|
| `utm_source`   | yandex, vk, instagram | Источник трафика             |
| `utm_medium`   | cpc, social, email  | Тип канала                     |
| `utm_campaign` | spring_cosmetology  | Название кампании              |
| `utm_term`     | лазерная эпиляция   | Ключевое слово / объявление    |
| `utm_content`  | banner_a            | Креатив или вариант объявления |
| `yclid`        | (авто из Директа)   | Идентификатор клика Яндекса    |
| `gclid`        | (авто из Google Ads)| Идентификатор клика Google     |
| `fbclid`       | (авто из Meta)      | Идентификатор клика Facebook/Instagram |

**Пример ссылки на главную:**

```
https://estetika.zvenfit.ru/?utm_source=yandex&utm_medium=cpc&utm_campaign=consult_march
```

**Сразу на форму записи:**

```
https://estetika.zvenfit.ru/form/?utm_source=yandex&utm_medium=cpc&utm_campaign=consult_march
```

---

## Как это работает

1. Клик по рекламе — в URL есть `?utm_...` (и при необходимости `yclid` / `gclid` / `fbclid`).
2. Сайт **запоминает** метки в браузере до **7 дней**.
3. Пользователь ходит по сайту — метки в адресной строке могут пропасть, но **сохраняются** в браузере.
4. Отправляет заявку на `/form/` или подписывается на рассылку в футере главной.
5. В Telegram приходит блок **«Маркировка»** с теми же метками.

**Пример сообщения:**

```
Новая заявка (Косметология)
Имя: Анна
Телефон: +7 (968) ...
Способ связи: WhatsApp
---
Маркировка:
source: yandex
medium: cpc
campaign: consult_march
```

---

## Правила

- **Окно 7 дней — скользящее:** каждый успешный визит или отправка формы с сохранённой маркировкой обновляет срок хранения. Если пользователь не возвращался более 7 дней, запись считается устаревшей.
- Если новый URL содержит другой **`utm_source`**, старые `utm_*` очищаются перед сохранением новых значений. При том же `utm_source` переданные параметры обновляются, а отсутствующие сохраняются.
- `yclid`, `gclid` и `fbclid` хранятся отдельно от `utm_*`; новый переданный идентификатор заменяет значение своего типа.
- **Прямой заход без новых UTM** использует ранее сохранённую маркировку, пока она не устарела. Блока «Маркировка» не будет только при отсутствии актуальной сохранённой записи и меток в URL.
- Сайт пробует сохранить метки в `localStorage`, `sessionStorage` и cookie. В приватном режиме или при блокировке всех этих механизмов метки попадут в заявку только если остаются в URL при отправке.

## Проверка после выкладки

1. Открыть:
   ```
   https://estetika.zvenfit.ru/?utm_source=test&utm_medium=cpc&utm_campaign=check
   ```
2. Перейти на `/form/` (без UTM в адресе).
3. Отправить тестовую заявку.
4. В Telegram: `source: test`, `medium: cpc`, `campaign: check`.

---

## Чего схема не делает

- Не заменяет Яндекс.Метрику — визиты и поведение по-прежнему в Метрике.
- Не отправляет данные в CRM — только Telegram.
- Не даёт 100% атрибуцию во всех браузерах (как любая клиентская схема).

---

## Рекомендации

- Минимум **`utm_source`** + **`utm_medium`** на каждую ссылку.
- Уникальный **`utm_campaign`** на кампанию (латиница, `_` или `-`).
- Разные креативы — через **`utm_content`**.
- Для Директа не удалять **`yclid`** из финальных URL.
